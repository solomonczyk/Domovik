# Domovik — регулярные проверки и уход за домом в Сербии

Многоязычный сайт и демо-клиентский портал для сервиса, который регулярно посещает объекты в Сербии, проверяет их состояние, присылает фото- и видеоотчёты и выполняет дополнительные услуги по договорённости.

> **Важно:** Domovik не является охранной организацией. Мы не оказываем услуги физической охраны, не обеспечиваем охрану объекта и не гарантируем его безопасность. Мы выполняем регулярные проверки состояния, документацию и дополнительные услуги по согласованию с владельцем.

## Стек

- **Next.js 16** (App Router, `--webpack`)
- **React 19 + TypeScript**
- **Tailwind CSS 4** + тёплая палитра (терракота, шалфей, охра, кремовый)
- **next-intl** — 5 языков: SR, EN, DE, HU, RU
- **lucide-react** — иконки
- **react-hook-form + zod** — формы и валидация
- **jose** — JWT-сессия в httpOnly cookie
- **framer-motion** — анимации и 3D-переходы
- Telegram Bot API — опциональные уведомления о заявках

## Страницы

- **Главная:** 3D-«барабан» из трёх слайдов (проверка, отчёт, дополнительные услуги), центрированный слайдер услуг, сравнение «до/после», блок отчёта, тарифы, FAQ и форма заявки.
- **Услуги и цены:** описание базового визита и пакетов.
- **Чек-лист визита:** 15 шагов проверки состояния объекта.
- **Договор и ответственность:** границы ответственности, порядок работы, обработка данных.
- **О нас:** история и зона обслуживания.
- **Контакты:** WhatsApp/Viber, телефон, email, форма.

## Личный кабинет (демо)

- Вход по email и паролю, сессия в подписанной httpOnly cookie (JWT, `jose`), без базы данных.
- `/dashboard` и вложенные страницы защищены Proxy и повторной проверкой сессии в `src/lib/dal.ts`.
- Визиты, отчёты, документы и заявки на дополнительные услуги.
- Отчёт по визиту: отдельная страница с печатью / сохранением в PDF.
- Данные визитов — из `src/lib/demoData.ts`; замена на БД выполняется в `src/lib/dal.ts`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run start
npm run lint
npx tsc --noEmit
```

На Windows можно использовать `start.bat` (dev) и `start-prod.bat` (production).

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните значения:

- `SESSION_SECRET` — обязателен для production; в dev при отсутствии генерируется случайный секрет процесса.
- `DEMO_LOGIN_EMAIL`, `DEMO_LOGIN_PASSWORD`, `DEMO_MODE` — демо-доступ к кабинету.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — опциональные уведомления.

`.env.local` и другие `.env*` не коммитятся (кроме `.env.example`).
