# 🏠 Domovik — Сервис присмотра за недвижимостью в Сербии

Современный многоязычный веб-сайт для бизнеса по регулярному присмотру за пустующими домами и квартирами в Сербии.

## 🚀 Стек технологий

- **Фреймворк:** Next.js 16 (App Router)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS 4 + кастомная палитра (Trust Blue & Nature Green)
- **Интернационализация (i18n):** `next-intl` (маршрутизация `/[locale]`)
- **Иконки:** `lucide-react`
- **Формы и валидация:** `react-hook-form` + `zod`
- **Бэкенд:** Next.js Route Handlers (`/api/contact`) с поддержкой Telegram Bot оповещений

## 🌐 Поддерживаемые языки (5 языков)

1. 🇷🇸 **Srpski (SR)** — основной язык по умолчанию
2. 🇬🇧 **English (EN)** — международная аудитория и экспаты
3. 🇩🇪 **Deutsch (DE)** — диаспора в DACH-регионе (Германия, Австрия, Швейцария)
4. 🇭🇺 **Magyar (HU)** — венгероязычная аудитория (Воеводина, Венгрия)
5. 🇷🇺 **Русский (RU)** — русскоязычные владельцы недвижимости

Переключатель языков размещен в шапке сайта, сохраняет текущий путь страницы при переключении.

## 📄 Реализованные страницы

1. **Главная (Landing Page):**
   - **Hero-блок:** заголовок, подзаголовок, CTA-кнопки, 3 ключевые метрики (100% видео, 24/7 протокол, юридический договор)
   - **Как это работает:** 4 пошаговых этапа с иконками и описанием
   - **Что входит в базовый визит:** сетка из 7 ключевых проверок + ссылка на подробный регламент
   - **Дополнительные услуги:** клининг, уход за двором, присмотр за питомцами, полив, проветривание, подготовка к приезду
   - **Для кого сервис:** 4 целевые группы (диаспора, иностранцы, моряки/дальнобойщики, посуточная аренда)
   - **Блок доверия:** видеосъемка, договор, геолокация и таймстампы, фиксированные цены
   - **Тарифы:** Базовый (€49/мес), Стандарт Плюс (€89/мес, хит продаж), Премиум (€149/мес)
   - **FAQ:** аккордеон с 6 ключевыми вопросами и ответами из ТЗ
   - **Форма заявки + Контакты:** прямые кнопки WhatsApp/Viber, валидация полей (Zod), аварийная линия 24/7
   - **Финальный CTA-блок**

2. **Услуги и цены (`/[locale]/services`):**
   - Детальный регламент, сравнение пакетов, условия для посуточных объектов (Airbnb/Booking)

3. **Чек-лист визита (`/[locale]/visit-checklist`):**
   - Пошаговый регламент из 15 пунктов: от фиксации GPS-прибытия и старта видеозаписи до отправки отчета и действий при аварии

4. **Договор и ответственность (`/[locale]/contract`):**
   - Границы ответственности, правила хранения ключей в сейфе, регламент ЧС при пожаре/взломе/потопе, кнопка скачивания образца договора

5. **О нас (`/[locale]/about`):**
   - История создания проекта, зона обслуживания (Воеводина и Белград), 4 базовых ценности

6. **Контакты (`/[locale]/contact`):**
   - Форма обратной связи, прямые ссылки WhatsApp/Viber, телефоны, график работы и зона охвата

## 🔐 Личный кабинет (демо-режим)

- Вход по email + паролю, сессия в подписанной httpOnly cookie (JWT, `jose`), без базы данных.
- `/dashboard` и все вложенные страницы защищены на уровне Proxy + повторная проверка сессии в серверном слое данных (`src/lib/dal.ts`).
- Выход из аккаунта через серверный action, редирект на локализованную страницу входа.
- Визиты: список отчётов, раскрытие полного протокола 15 пунктов, фото с таймстампами, показания счётчиков и статус безопасности.
- Отчёт по визиту: отдельная страница `/[locale]/dashboard/visits/[id]` с печатью / сохранением в PDF.
- Заявка на дополнительную услугу отправляется через защищённый `/api/service-requests` (дублируется в Telegram при наличии токена).

## ⚡ Быстрый запуск в 1 клик (Windows)

- Просто дважды кликните по файлу **`start.bat`** в корне проекта:
  - Он автоматически проверит наличие `node_modules` (при необходимости доустановит).
  - Запустит локальный сервер разработки.
  - Через 3 секунды автоматически откроет браузер на `http://localhost:3000`.

Для запуска оптимизированной production-версии используйте **`start-prod.bat`**.

## 🛠️ Ручной запуск через консоль

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (с флагом --webpack)
npm run dev

# Проверка типов TypeScript
npx tsc --noEmit

# Сборка проекта
npm run build

# Запуск production-сервера
npm run start
```
